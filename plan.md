# План исправлений script.py

## Безопасность

- [x] Ограничить права скачанного файла: в `process_file` (script.py:325-327) заменить
      `os.chmod(tmp_path, 0o666 & ~umask)` на `os.chmod(tmp_path, 0o644 & ~umask)`,
      чтобы при `umask 000`/`002` файл не оказался доступным на запись группе и всем.

- [x] Прогнать удалённые пути через `check_value`: в `get_paths` (script.py:117-133) после
      `p = p.strip()` вызвать `check_value(p, f"путь {p!r}")` (ошибку перевести в `fail_config`),
      так как `sys.argv`, `SEAFILE_PATHS` и `SEAFILE_PATH` читаются минуя `env()` и управляющие
      символы попадают в лог и в имя локального файла.

- [x] Перенести lock-файл из общего `/tmp`: в `main` (script.py:348-349) выбирать каталог
      `XDG_RUNTIME_DIR` → `/run/user/<uid>` → `DEST_DIR`, а не `tempfile.gettempdir()`.

- [x] Проверить владельца lock-файла: после `os.open` сверить
      `os.fstat(lock_fd).st_uid == os.getuid()` и завершаться с кодом 2, если файл чужой.

- [x] Обработать `OSError` при открытии lock-файла (`EACCES` из-за squatting) отдельным
      сообщением, чтобы причина была видна в логе, а не только как общая ошибка.

- [x] Не возвращать 0, когда lock занят: логировать предупреждение и возвращать отдельный
      код (например 3), иначе постоянно удерживаемый lock выглядит для cron как успех.

- [x] Ограничить размер загрузки: добавить в `curl` параметр `max_filesize` и передавать
      `--max-filesize <remote_size>` при скачивании (script.py:311), размер уже известен
      из `file/detail/`.

- [x] Зафиксировать путь к curl: найти его один раз через `shutil.which("curl")` при старте
      (или прописать `/usr/bin/curl`), проверить, что файл существует, и использовать
      абсолютный путь в `cmd` (script.py:186) вместо поиска по `PATH`.

## Валидация конфигурации

- [ ] Отвергать `#` и `?` в `SEAFILE_URL`: в `parse_base_url` (script.py:79-85) проверка
      `u.query`/`u.fragment` пропускает `https://host/#`, так как фрагмент пустой —
      добавить явную проверку символов в исходной строке.

- [ ] Нормализовать сравнение хоста в `is_trusted_url` (script.py:153-161): сравнивать
      `(hostname, port or 443)` вместо строки `netloc`, чтобы download-ссылка с явным
      `:443` не отвергалась.

- [ ] Разрешить отдельный хост файл-сервера: добавить необязательную переменную
      `SEAFILE_FILE_SERVER_URL` (только https) и считать доверенным также её хост,
      для конфигураций Seafile с собственным `FILE_SERVER_ROOT`.
